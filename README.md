# CAPRI // Project Capricorn (Desktop AI Construct)

Интерактивный наэкранный компаньон и ассистент в стиле **Cyberpunk 2077 / Edgerunners**.

## Что умеет Капри:

1. **Плавающая наэкранная звёздочка (Desktop Pet Widget)**:
   * 8-конечная киберпанк-звезда (красно-бирюзовая с циклопическим глазом-ядром по центру), выполненная в векторе через `QPainter`.
   * **Плавное парение (Drift)**: плавно и неспешно дрейфует по экрану с легким покачиванием и пульсацией.
   * **Перетаскивание**: можно схватить мышкой и перетащить в любую точку экрана.
   * **Динамическая статус-плашка**: `DORMANT`, `WATCHING`, `LISTENING`, `THINKING`, `TALKING`, `ONLINE`.
   * **Контекстное меню** по правому клику (открыть чат, проверить экран прямо сейчас, говорить в микрофон, сбросить позицию, выйти).

2. **Screen Watching (Зрение) + Всплывающее диалоговое окно**:
   * Раз в случайный интервал от **30 секунд до 5 минут** (или по команде `/watch`) Капри делает скриншот и оценивает, чем занят пользователь.
   * Статус переключается в `WATCHING`, и рядом со звёздочкой **раскрывается киберпанк-окно диалога**.
   * В окне появляется анимированный аватар конструкта с неоновым визором и шевелящимся при речи ртом, а реплика Капри печатается с эффектом печатной машинки.

3. **Интерактивный чат**:
   * Внизу диалогового окна есть строка ввода: можно сразу напечатать ответ и нажать `Enter` или кнопку `SEND ↵`.
   * Капри ответит прямо в этом окне с обновлением статуса и анимацией аватара.

4. **Голосовой ввод по клавише `\`**:
   * Нажатие `\` в любой момент запускает запись голоса с микрофона (статус меняется на `LISTENING [---]`).
   * Повторное нажатие `\` отправляет речь в распознавание (STT), открывает диалоговое окно и передает реплику Капри.

5. **Параллельная работа с терминалом**:
   * Все события дублируются в терминал VS Code с яркой киберпанк-расцветкой. В терминале также можно вводить команды (`/watch`, `/status`, `/clear`, `/exit`).

---

## Установка зависимостей:

Перед первым запуском установите необходимые библиотеки из `requirements.txt`:

```powershell
pip install -r requirements.txt
```

## Запуск:

В терминале VS Code:
```powershell
python main.py
```
*(Или запусти двойным кликом файл `run_capri.bat`)*

---

## Настройка AI-мозга (Gemini API):

Создай файл `.env` в корне папки:
```env
GEMINI_API_KEY=твой_ключ_от_Google_AI_Studio
GEMINI_MODEL=gemini-2.5-flash
(Примечание: 2.5-flash имеет мало лимиотов. Если не хотите платить, но хотите больше общения,
то используйте GEMINI_MODEL=gemini-flash-lite-latest. Учтите что эта модель 'тупее' обычного flash)
```
Бесплатный ключ можно взять на [Google AI Studio](https://aistudio.google.com/app/apikey).
